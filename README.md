# 丹内建機サービス 見積もりアプリ（Version 1）

父（丹内建機サービス）の見積もり作成時間を短くするための社内ツールです。
経験に頼っていた「単価・人数・日数・掛け率」の判断を入力に置き換え、見積もり金額のたたき台を数分で出せるようにします。
判断理由と実績（実際にかかった人日・費用）を残し、次回の見積もり精度を上げることも目的です。

## できること

- 作業条件（人数・日数・負荷・消耗品/技術料の有無）から推奨1人1日単価を提示
- 単価候補（25,000〜72,000円）からの選択と手動調整
- 工賃・材料費（仕入れ × 掛け率）・消耗品費・技術料・諸経費・消費税の自動合算
- 単価が低すぎる／人日が過大などのリスクアラート
- 単価・人数日数・納期の「判断理由メモ」を保存
- 見積もりの一覧・詳細・編集
- 作業完了後の実績入力と、見積もりとの差分メモ

## 技術構成

- Next.js 16（App Router / JavaScript）+ React 19
- Supabase（PostgreSQL / Auth / RLS）
- Vercel でデプロイ
- ログインは管理者パスワードのみ（父・本人で共有）

## 画面

| パス | 内容 |
| --- | --- |
| `/` | 使い方ガイド（ログイン不要） |
| `/login` | 管理者パスワード入力 |
| `/estimates` | 見積もり一覧 |
| `/estimates/new` | 新規見積もり作成（最優先画面） |
| `/estimates/[id]` | 見積もり詳細 |
| `/estimates/[id]/edit` | 見積もり編集 |
| `/estimates/[id]/result` | 実績入力・差分メモ |

## 入力ルール

- 金額欄は **整数のみ**（例: `20000`）。小数点・カンマは入力できず、警告が出て保存できません。
- 想定日数・材料の数量は小数可（半日 = `0.5`）。
- 延べ人日 = 作業人数 × 想定日数。これに単価をかけたものが工賃です。

## ローカル起動
