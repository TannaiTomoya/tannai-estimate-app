# 見積もりアプリ Version 1 画面設計

前提: `docs/requirements.md`、および画面設計の決定事項（Q1〜Q5）を反映する。

## 方針

- `/estimates/new` は1ページに全セクションを並べ、見出しで区切る
- 新規と編集は同じフォーム構成を使い回し、URLだけ分ける
- 保存成功後は詳細画面 `/estimates/[id]` へ遷移する
- 入口は見積もり一覧 `/estimates`
- Version 1では `/dashboard` と `/settings` は作らない

## 画面一覧

実装順は次のとおり。実績入力は実装順では最後だが、Version 1完了に必須とする。

| 画面名 | パス | 目的 | 優先度 | 実装順 |
|---|---|---|---|---|
| 見積もり新規作成 | `/estimates/new` | 1件の見積もりを入力・計算・保存する | 高 | 1 |
| 見積もり詳細 | `/estimates/[id]` | 保存内容・判断理由・実績の確認 | 高 | 2 |
| 見積もり一覧 | `/estimates` | 過去案件の確認と新規作成への入口 | 中 | 3 |
| 見積もり編集 | `/estimates/[id]/edit` | 提示前の見積もりを修正する | 中 | 4 |
| 実績入力 | `/estimates/[id]/result` | 実績と差分メモを記録する | 高（Version 1完了必須） | 5 |

## 画面遷移

```
/estimates（一覧）
  ├─ → /estimates/new（新規作成） → 保存 → /estimates/[id]（詳細）
  └─ → /estimates/[id]（詳細）
        ├─ → /estimates/[id]/edit（編集） → 保存 → /estimates/[id]
        └─ → /estimates/[id]/result（実績） → 保存 → /estimates/[id]
```

## 1. 見積もり一覧（`/estimates`）

### 役割
ログイン後の最初の画面。過去見積もりを確認し、新規作成へ進む。

### 表示項目
- 見積もり日
- 案件名
- 顧客名
- 合計（税込）
- ステータス（下書き / 提示済み / 受注 / 失注 / 完了）
- 実績入力済みかどうか
- 新しい順に並べる

### 操作
- 「新規作成」→ `/estimates/new`
- 行クリック（または詳細リンク）→ `/estimates/[id]`

### 使わないもの（Version 1）
- 検索・絞り込み
- ダッシュボード用サマリー

## 2. 見積もり新規作成（`/estimates/new`）

### 役割
Version 1の最優先画面。1ページで見積もりのたたき台を作り、保存する。

### レイアウト
縦スクロールの1ページ。以下のセクションを上から順に配置する。

#### セクション1: 案件情報
- 案件名（必須）
- 顧客名（必須）
- 作業場所（任意）
- 見積もり日（必須）
- 顧客提示予定納期（任意）

#### セクション2: 作業条件（WorkConditionForm）
- 作業人数
- 想定日数
- 作業負荷（低 / 中 / 高）
- 消耗品を含むか
- 技術料を含むか
- 作業内容の簡単な説明（任意）
- 表示: 延べ人日（人数 × 日数）

#### セクション3: 単価と工賃（LaborCostCalculator）
- 推奨単価と根拠ライン名（参考表示）
- 単価候補からの選択
- 手動調整（自由入力）
- 採用単価と推奨単価の差額
- 表示: 工賃 = 人数 × 日数 × 採用単価

#### セクション4: 材料費（MaterialCostForm）
- 材料明細（複数行）: 材料名、仕入れ単価、数量
- 掛け率
- 表示: 仕入れ合計、材料費

#### セクション5: その他費用
- 消耗品費
- 技術料
- 諸経費

#### セクション6: 合計とアラート（EstimateSummary / EstimateRiskAlert）
- 内訳（工賃・材料費・消耗品・技術料・諸経費）
- 小計（税抜）、消費税（10%）、合計（税込）
- 1人日あたり実質単価
- リスクアラート（該当時のみ）

#### セクション7: 判断理由メモ（EstimateReasonMemo）
- 単価を決めた理由
- 人数・日数を決めた理由
- 納期を決めた理由（任意）
- 未入力時は注意表示（保存は可能）

#### セクション8: 保存
- ステータス選択（初期値は下書き）
- 保存ボタン
- 成功後 → `/estimates/[id]`

### 主要コンポーネント
- EstimateForm（全体の入れ物）
- WorkConditionForm
- LaborCostCalculator
- MaterialCostForm
- EstimateSummary
- EstimateRiskAlert
- EstimateReasonMemo

## 3. 見積もり詳細（`/estimates/[id]`）

### 役割
保存後の着地画面。内容確認と、編集・実績への導線。

### 表示項目
- 案件情報
- 作業条件
- 推奨単価と採用単価
- 内訳と合計
- アラート（保存時点で該当したもの）
- 判断理由メモ
- 実績（入力済みなら表示）
- 実績差分メモ（入力済みなら表示）

### 操作
- 「編集」→ `/estimates/[id]/edit`
- 「実績入力」→ `/estimates/[id]/result`
- 「一覧へ」→ `/estimates`

## 4. 見積もり編集（`/estimates/[id]/edit`）

### 役割
提示前の見積もりを修正する。

### 方針
- `/estimates/new` と同じセクション構成・同じフォームを使う
- 既存値を初期表示する
- 保存成功後 → `/estimates/[id]`

## 5. 実績入力（`/estimates/[id]/result`）

### 役割
作業後の実績を記録し、見積もりとの差分を残す。

### 表示（参考）
- 見積もり時点の人数・日数・金額など（読み取り専用）

### 入力項目（EstimateResultForm）
- 実際の作業人数・作業日数
- 実際の材料仕入れ合計
- 実際の消耗品費・技術料・諸経費
- 実際の受注金額（税抜）
- 作業完了日
- 差分の理由
- 次回に向けた気づき（任意）

### 表示・出力
- 見積もりと実績の差（人日、費用、金額、実質単価）

### 操作
- 保存成功後 → `/estimates/[id]`

## Version 1で作らない画面

- `/dashboard`
- `/settings`
- 独立したトップページ（必要なら `/` から `/estimates` へ誘導する程度）
